# Tableau Dashboards

This folder documents the Tableau dashboards created for the San Antonio Zillow housing analysis.

## Dashboard 1 — San Antonio Housing Market

Provides an overview of the San Antonio housing market, including:

- Total listings
- Median and average listing price
- Median price per square foot
- Median days on Zillow
- Zestimate coverage
- Listing price by ZIP code
- Price per square foot by ZIP code
- Listing price distribution
- Average listing price by bedroom count
- Listing price versus living area

## Dashboard 2 — Zestimate Analysis

Examines the relationship between Zillow listing prices and Zestimate values.

Key analyses include:

- Listing price versus Zestimate
- Potential opportunities by ZIP code
- Potential Zestimate gap by property
- Total potential Zestimate gap by ZIP code
- Zestimate gap percentage

## Dashboard 3 — Investment Opportunities

Highlights listings where the Zestimate exceeds the asking price.

Key metrics include:

- Potential opportunities
- Average potential gap
- Median potential gap
- Average potential gap percentage
- Deal Score
- Zestimate gap percentage
- Price per square foot

The dashboards are designed to translate the analytical results into business-oriented insights for housing market analysis.
