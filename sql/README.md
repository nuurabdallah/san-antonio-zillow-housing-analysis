
# SQL Analysis

This folder contains the PostgreSQL scripts used to analyze the San Antonio Zillow housing data.

The SQL workflow includes:

- Database and schema creation
- Analytical table creation
- Data quality validation
- Market-level analysis
- ZIP code analysis
- Zestimate analysis
- Investment opportunity analysis
- Tableau data preparation

The SQL analysis is designed to demonstrate practical relational database, aggregation, window function, ranking, and analytical SQL skills.
