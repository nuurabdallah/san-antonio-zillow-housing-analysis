This folder documents the datasets used in the San Antonio Zillow housing analysis project.

## Authoritative Analytical Dataset

The primary analytical dataset contains Zillow housing listings used throughout the project's SQL analysis, Tableau dashboards, exploratory analysis, and machine learning workflow.

Key fields include:

- Listing price
- ZIP code
- Bedrooms
- Bathrooms
- Living area
- Property type
- Days on Zillow
- Zestimate
- Tax assessed value
- Lot area
- Price per square foot
- Price change
- Log-transformed listing price

## Data Privacy

Raw and processed datasets are not committed to this repository.

The repository contains documentation and code describing how the data was prepared and analyzed.
